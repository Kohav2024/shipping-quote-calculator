# מחשבון הצעת מחיר לשילוח

אתר סטטי וציבורי להצעת מחיר ממחירון הספנות (ZIM, YML, OOCL, ו-MSC — הודו וסרי לנקה; המחירון שנטען בתוקף עד 31.10.2026 ומוצג לעיון כשפג תוקף). אין צורך בחשבון או בסיסמה — שולחים לאנשי המכירות את הקישור.

**כתובת חיה:** https://kohav2024.github.io/shipping-quote-calculator/

## קבצים

- `index.html` — הממשק (עברית, מימין לשמאל, מותאם לנייד)
- `data.js` — כל נתוני המחירון (חברות, מסלולים, תוספות, תוקף, הערות)
- `.nojekyll` — כדי ש-GitHub Pages יגיש את הקבצים כמו שהם

## עדכון מחירון

שולחים את קובץ המחירון החדש בשיחה כאן. מעדכנים רק את `data.js` (בלי לשנות את `index.html`, אלא אם המבנה עצמו השתנה), מעלים לענף `main`, והאתר מתעדכן אחרי פרסום Pages.

אין שירות בתשלום ואין שרת נפרד: האתר רץ כ-GitHub Pages מענף `main`, מתיקיית השורש.
